# Ty's Spotless Solutions

## Project Overview

**Ty's Spotless Solutions** is a modern, professional website for a residential snow removal service business based in Portage, Michigan. The website provides potential customers with comprehensive information about snow removal services, company details, and an easy way to request quotes.

## Brief Description

A responsive, single-page web application designed to showcase professional snow removal services. The website features a clean, modern design with intuitive navigation, detailed service information, and a contact form that facilitates customer inquiries through email integration.

## Technologies Used

### Core Technologies
- **React 18.2.0** - JavaScript library for building user interfaces
- **TypeScript** - Type-safe JavaScript for enhanced code quality and developer experience
- **React Scripts 5.0.1** - Build tooling and development server

### Styling & UI
- **Tailwind CSS 3.3.0** - Utility-first CSS framework for responsive design
- **Autoprefixer 10.4.14** - PostCSS plugin for vendor prefixes
- **Lucide React 0.263.1** - Beautiful, consistent icon library (Snowflake, Phone, MapPin, Clock, CheckCircle, Mail icons)

### Analytics & Monitoring
- **Vercel Analytics 1.6.1** - Performance and user analytics tracking

### Development Tools
- **Node.js/npm** - Package management and build system
- **ESLint** - Code quality and consistency

## Project Structure

```
spotless-solutions/
├── public/
│   └── index.html          # HTML template with meta tags and site description
├── src/
│   ├── App.tsx             # Main application component (TypeScript)
│   ├── App.js              # Main application component (JavaScript)
│   ├── TysSpotlessSolutions.tsx  # Core business logic and UI (TypeScript, 398 lines)
│   ├── TysSpotlessSolutions.js   # Core business logic and UI (JavaScript, 451 lines)
│   ├── index.js            # Application entry point (React 18 root)
│   └── index.css           # Global styles and Tailwind directives
├── package.json            # Project dependencies and scripts
└── tailwind.config.js      # Tailwind CSS configuration
```

**Note**: The project includes both TypeScript (.tsx) and JavaScript (.js) versions of the main components to support flexible development workflows.

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm start
```
Runs the app in development mode at [http://localhost:3000](http://localhost:3000)

### Build
```bash
npm run build
```
Creates an optimized production build in the `build` folder

### Testing
```bash
npm test
```
Launches the test runner in interactive watch mode
